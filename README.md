# WOP — Couple Challenge

Eine mobilefreundliche Date-Night-Challenge-Webseite für erwachsene Paare.

## Funktionen
- Auswahl: Er, Sie, beide oder zufällig
- Fünf Level mit insgesamt mehr als 50 Aufgaben
- Zufällige Aufgabe und Überspringen
- Pause/Beenden jederzeit möglich
- Altersbestätigung (18+) und klare Consent-Regeln
- Kein Backend, keine Anmeldung und keine Speicherung persönlicher Daten

## Lokal starten
Einfach `index.html` im Browser öffnen.

## GitHub Pages aktivieren
1. Repository **Settings → Pages** öffnen.
2. Bei **Build and deployment → Source** **GitHub Actions** auswählen.
3. Den Workflow unter **Actions** ausführen oder eine Änderung nach `main` pushen.
4. Nach erfolgreichem Deployment ist die Seite unter https://buhntech-dev.github.io/Wop/ erreichbar.

Der Workflow liegt unter `.github/workflows/deploy.yml`.
